# 🌿 GreenDen

GreenDen is a responsive plant shopping website built using **HTML and Tailwind CSS**. 
The website provides a simple and clean interface for exploring plants, viewing products,
reading customer reviews, and contacting the store.
## 🔗 Live Demo

[GreenDen Link](https://jeya-0309.github.io/GreenDen/)

## 🚀 Features

- 📱 Responsive navigation bar
- 🌱 Home page with plant introduction
- 🪴 About Us section
- 🌿 Large assortment of plants
- 🚚 Free and fast shipping information
- 📞 24/7 customer support
- ⭐ Best Seller products section
- 💬 Customer Reviews section
- 📧 Newsletter subscription section
- 📩 Contact Us page
- 📱 Responsive design for mobile, tablet, and desktop
- ✨ Hover effects on product images

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- CSS Flexbox
- CSS Grid
- SVG Icons
- Responsive Design
